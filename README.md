# ✈️ Moza Cockpit Flight Profiles

Welcome to this repository. It contains pre-configured profile presets for
the MOZA AB6 flight simulator base, intended for Microsoft Flight Simulator
2024.

## 📂 File Index

Each entry includes the filename (linked to the file), profile name stored in
the preset, preset format version, and a short description to help you choose
the right profile. All profiles target Microsoft Flight Simulator 2024 and the
MOZA AB6.

## 🎮 How to Use These Files

Import the `.preset` files from the `profiles` folder into MOZA Cockpit.

Feel free to contribute improvements or additional MOZA Cockpit profiles.
